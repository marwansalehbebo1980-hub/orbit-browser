# ORBIT — Browser Homepage

A stylish, responsive browser homepage made with **HTML, CSS, and JavaScript**.

## Project files

- `index.html` — page structure and content.
- `style.css` — colors, layout, responsive design, hover effects, and animations.
- `script.js` — search, theme switching, modal behavior, and adding shortcuts.

## Run in Visual Studio Code

1. Extract `ORBIT_VSCode_Project.zip` into a folder.
2. Open Visual Studio Code.
3. Choose **File → Open Folder...** and select the extracted `ORBIT_VSCode_Project` folder.
4. Open `index.html`.
5. Right-click inside the file and choose **Open with Live Server** if you have the Live Server extension installed.
   - Or simply double-click `index.html` in File Explorer to open it in your browser.

## Notes

- Search opens Google results for text and opens recognized website addresses directly.
- Website shortcuts added from the dialog exist for the current page session only. Refreshing the page resets custom shortcuts.
- This is a browser homepage, not a standalone browser engine like Chrome.
